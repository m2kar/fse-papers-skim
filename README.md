# FSE 论文略读 · 组会展示页面

51 篇 FSE 论文、每篇一页、约 30 秒讲解的组会演示工具。纯前端、零依赖，运行时直接 fetch 两个 CSV，改完 CSV 刷新页面即生效。

## 使用

**在线访问（GitHub Pages）**：<https://m2kar.cn/fse-papers-skim/>

**双击 `启动.command`**（macOS）——自动开启本地服务器并在浏览器中打开页面。

手动方式：

```bash
cd 本目录
python3 -m http.server 8931
# 浏览器访问 http://localhost:8931/index.html
```

> 页面通过 fetch 读取 CSV，**不能**直接双击 index.html（file:// 无法读本地文件）；若误双击，页面会提示如何启动。结束演示后在终端按 Ctrl+C 关闭服务器。

## 页面结构

`封面 →（类别过渡页 + 论文页）× 6 类 → 结尾`，共 59 页，随时可按 `G` 调出目录总览跳转。

- **类别页**：口诀大字水印 + 类别名 + **类别综述段落**（综述风格总结本类全部论文，维护在 `分类思路.csv` 的「类别综述」列）+ 本类论文速览
- **论文页**：上方为类别徽章 / 中文标题 / 英文原题 / 一句话总结，中部为「问题挑战 · 核心方法 · 主要效果」三列卡片，下方一行左侧为作者团队、右侧可展开**详情抽屉**（完整作者单位、中英摘要、关键词、PDF 原文嵌入）
- **底栏**：六类六色分段进度条、篇目计数、计时器

## 快捷键

| 按键 | 功能 | 按键 | 功能 |
|---|---|---|---|
| `→` / `空格` / `PageDown` / `N` | 下一篇 | `←` / `PageUp` / `P` | 上一篇 |
| `D` 或 `↓` | 展开/收起详情抽屉 | `G` | 目录总览（`Esc` 关闭）|
| `1`–`6` | 跳到第 N 类 | `F` | 全屏 |
| `T` | 计时 开始/暂停 | `R` | 计时归零 |
| `Home` / `End` | 首/末页 | 点击左/右半屏 | 上一页/下一页 |

翻页笔（映射 PageDown/PageUp）天然可用。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 展示页面（单文件，内联 CSS/JS，运行时解析 CSV） |
| `启动.command` | macOS 双击启动：开服务器 + 打开浏览器 |
| `papers.csv` / `分类思路.csv` | 数据源（类别综述在「分类思路.csv」最后一列） |
| `pdfs/` | 51 篇原文 PDF |

> 若个别浏览器不显示抽屉内嵌 PDF，点抽屉右上角「↗ 新窗口打开」即可。
